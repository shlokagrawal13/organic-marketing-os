# Design system

Custom vanilla CSS; no Tailwind dashboard template. Persistent dark green workspace navigation, lime brand mark, blue actions, neutral content surfaces, readable system typography, restrained borders and a separate Creative DNA editing surface. CSS variables define light/dark surfaces, text, borders and accents.

Reusable patterns: primary/secondary buttons, labeled forms, status pills, panels, empty/loading/error states, contextual notices, native dialog for campaigns, data tables, calendar cells, scene cards, review checklist and version history.

The mobile navigation is collapsible; wide tables/calendars scroll within their own containers. Focus styles, semantic buttons/labels, a skip link, reduced-motion styles and native dialog keyboard behavior are included. Browser tests check horizontal overflow on registration and content views. A formal WCAG audit, screen-reader review and complete 200% zoom review remain pending.

Media surfaces add searchable/filterable asset cards with image/video/audio previews, labelled upload progress and rights confirmation, scene attachment controls, format/music options, status/history cards, a real video player, downloads and explicit review acknowledgment. Mobile controls stack into one column; the preview remains within the viewport. The media browser scenario checks page overflow and records desktop, dark and mobile evidence. A complete accessibility audit remains pending.
