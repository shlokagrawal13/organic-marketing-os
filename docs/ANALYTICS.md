# Analytics status

The UI reports only database content counts and actual logged AI provider attempts. Workflow bars are displayed only if content exists. Counts explicitly identify latest-100 limits. Model cost estimates are shown only if token counts and operator-supplied rates exist. Exports include their generation time and limits.

Reach, followers, engagement, watch time, conversions and revenue are unavailable because no external source is connected. There are no invented growth charts, time-saved estimates or attribution claims.

Pending: asynchronous official-platform ingestion, raw/source/timestamp metadata, metric normalization, stable reporting windows, cumulative-vs-incremental semantics, deduplication, campaign/platform/post drill-down, provenance, insights, experiments, attribution and report exports beyond JSON.
