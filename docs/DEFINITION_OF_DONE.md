# Definition of done

A feature requires implemented behavior, backend integration, input/error/loading/empty states, tenant and role tests, meaningful workflow tests, visual review where applicable, and synchronized docs. Local test evidence must state its dependencies and mocks.

Production completion additionally requires native infrastructure, staging HTTPS/auth/proxy verification, authorized live-provider tests, recovery testing, monitoring and the full master acceptance flow. The current release does not meet that standard. Do not convert “implemented,” “fixture tested” or “configured” into “production verified.”
